## Subir desde el navegador

1. Crea un repositorio llamado `tesoem-prestamos-materiales`.
2. Si prefieres revisar primero, créalo privado; la publicación pública depende de los permisos del trabajo.
3. Descomprime el ZIP y sube el contenido de la carpeta del proyecto: `README.md` e `index.html` deben quedar en la raíz del repositorio. No subas el ZIP como único archivo.
4. Añade la descripción y los temas anteriores.
5. Cuando esté público y revisado, destácalo desde tu perfil.

También puedes subir la carpeta con Git o GitHub Desktop.

## Organización del perfil

- Proyectos destacados: aplicaciones completas como este sistema.
- En desarrollo: proyectos con una meta y un estado explícitos.
- Aprendizaje: ejercicios agrupados por lenguaje, por ejemplo `practicas-javascript`, `practicas-python` o `practicas-php`.
- React: repositorio propio para sus prácticas cuando comiences a usarlo; es una biblioteca de JavaScript.
- HTML y CSS: tecnologías de estructura y estilos de las interfaces.

No listes una tecnología como dominada solo porque quieras aprenderla. Separa lo utilizado en proyectos de lo que estás aprendiendo.

## GitHub y PHP

Puedes almacenar y mostrar código PHP en los repositorios de GitHub. GitHub Pages publica archivos estáticos y no ejecuta PHP ni un backend Python. Para una app PHP funcional necesitas un servidor que lo ejecute y puedes enlazar su demo desde el README.

El frontend de este proyecto puede alojarse como archivos estáticos, pero el inicio de sesión y el panel siguen necesitando Apps Script y Sheets configurados. Publicar los archivos no sustituye el backend.
